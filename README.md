# 🏨 HostalManager
**Sistema de Gestión de Reservas y Disponibilidad para Pequeños Alojamientos Turísticos**  
Proyecto de FCT (Formación en Centros de Trabajo) — *Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW)*.

---

## 📌 Descripción del Proyecto
**HostalManager** es un Producto Mínimo Viable (MVP) acotado a 40 horas de desarrollo efectivo, diseñado para centralizar la gestión de reservas del **Hotel Restaurante Las Vegas** (Ribas de Sil, Lugo). 

El sistema consta de:
1. **Público (Huéspedes):** Motor de búsqueda de disponibilidad por fechas y solicitud de reserva directa sin registro obligatorio.
2. **Privado (Administración):** Panel protegido para el personal con control de estados (`confirmed`, `cancelled`, `completed`) y mantenimiento de habitaciones.

---

## 🛠️ Stack Tecnológico
* **Backend:** PHP 8.3+ / Laravel 13 (Arquitectura MVC, Eloquent ORM, Blade)
* **Base de Datos:** MariaDB 11.4 (SGBD Relacional, 7 tablas)
* **Entorno & Contenedores:** Docker Desktop + Laravel Sail sobre **WSL2 (Ubuntu 24.04 LTS)**
* **Frontend:** HTML5, CSS3, Bootstrap 5 (Responsive & WCAG AA)
* **Control de Versiones:** Git & GitHub
